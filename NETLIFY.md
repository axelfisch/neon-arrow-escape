# Neon Arrow sur Netlify

## Depuis GitHub

- Repository : axelfisch/neon-arrow-escape.
- Build command : `npm run build:netlify`.
- Publish directory : `site`.
- Node : 22.

Le déploiement reconstruit les sources ; il ne republie plus une ancienne copie compilée sans compilation.

## Déploiement manuel

Le ZIP `neon-arrow-netlify.zip` contient le site statique prêt à déployer : index.html, assets/, _redirects et licenses/. Téléverser ce ZIP sur le projet Netlify choisi.
